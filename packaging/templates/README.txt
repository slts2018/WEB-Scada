WebScada packaged runtime

1. Install/extract to a writable folder (e.g. C:\WebScada). Do NOT use Program Files.
2. Double-click start.bat (or the desktop shortcut).
3. Browser opens: http://127.0.0.1:8787/designer

If the window flashes and nothing opens:
- Run diagnose.bat in the install folder
- Or open: %TEMP%\WebScada-launch.log
- Also check: data\launch.log and data\server.log

Stop: stop.bat
